INSTALL

三步开始游戏

不需要安装器，也不依赖额外的运行库。解压后即可开始。

解压

把下载的 ZIP 解压到一个有写入权限的目录。建议路径中不要包含特殊字符，以免影响存档。

启动

Windows 双击 SteamNavigator.exe。Linux 进入解压目录，为可执行文件添加执行权限后运行。

启航

选择「开始新航行」，按新手引导备好煤与水，再打开海图选择第一段航线。

Linux 启动示例：chmod +x SteamNavigator.x86_64 && ./SteamNavigator.x86_64

FAQ

常见问题

游戏怎么启动？

Windows 解压后双击 SteamNavigator.exe。Linux 解压后，在终端里为可执行文件添加执行权限并运行；如果系统提示权限不足，请先执行 chmod +x。

支持简体中文吗？

支持。游戏默认使用简体中文，也可以在设置中切换为英文。界面与内容文本都已完成本地化。

存档保存在哪里？

存档由游戏自动管理，保存在系统的用户数据目录中。游戏在关键节点自动存档，也可以在设置中调整自动存档行为。

为什么版本号里带有 dev？

目前提供的是公开的开发中版本，功能与平衡仍在持续调整。稳定版本会在后续发布中提供；开发日志页会记录每一次主要变化。

更新时可以直接覆盖旧文件吗？

建议把新版本解压到新的目录，再确认存档位置。直接覆盖旧目录一般也能启动，但保留一份旧版本更稳妥。

遇到问题去哪里反馈？

可以在 发布页 查看版本说明与已知问题，或通过项目页面提交反馈。反馈时附上系统信息与复现步骤会更容易定位。
