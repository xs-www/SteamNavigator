# Steam Navigator UI Foundation Spec V1

> 状态：生产前置规范。视觉上服从 [SN Visual Baseline V1](UI_VISUAL_BASELINE.md)，但不把 `UI Kit Concept V1` 视为逐像素生产稿。

## 1. 适用范围与优先级

本规范定义 UI 生产所需的材质族、基础尺寸、九宫格、安全文字区域、字体、颜色、交互状态和动效。发生冲突时优先级如下：

1. 可读性、可操作性与无障碍要求。
2. 本规范中的数值和状态契约。
3. SN Visual Baseline V1 的风格与材质关系。
4. UI Kit Concept V1 的具体构图与装饰。

业务页面不得临时新增边框、圆角、颜色或动效。确有新语义时，先扩展本规范和 UI Kit 展示场景，再进入页面。

## 2. 设计画布与缩放

- 逻辑设计画布：`1600 × 900`，与当前 Godot `canvas_items + expand` 配置一致。
- 最小验收窗口：`960 × 540`；标准验收窗口：`1440 × 900`；宽屏验收窗口：`1920 × 1080`。
- 视觉资产以逻辑像素设计，源文件至少按 2× 尺寸绘制；导入后由 Godot 根据逻辑尺寸显示。
- 栅格基数：4 px。布局、内边距、图标和交互目标尽量落在 4 px 倍数上。
- 小于 1 px 的描边不得承担关键信息；缩放后低于 1 物理像素的装饰允许消失。
- `960 × 540` 下可以隐藏装饰、次要说明与非关键列，不能缩小关键文字或操作目标来硬塞内容。

## 3. 四个主要材质族

### 3.1 Brass Steel / 黄铜钢板

用途：HUD、按钮、弹窗外框、仪表、输入槽、状态条和结构容器。

- 主体是深青黑喷漆钢板；黄铜只用于承力边、角件、焦点和主要操作。
- 允许三种有明确用途的结构：`frame` 外框、`plate` 交互铭牌、`recess` 内嵌仪表槽。
- `recess` 不是第五种材质；它继承钢板色相，只改变明度和受光方向。
- 禁止仅为了“更丰富”增加银边、木边、双铜边等无语义变体。

### 3.2 Parchment / 羊皮纸

用途：市场账册、委托、任务、结算回执、说明和 Tooltip。

- 暖纸底、深墨文字、不规则但稳定的外轮廓。
- 纸夹、蜡封、盖章、编号属于可选语义装饰，不参与九宫格拉伸。
- 纸张不得铺满全屏；必须由钢板、绳索、夹板或场景结构承托。

### 3.3 Blueprint / 蓝图

用途：船厂、部件、安装槽、性能比较和技术说明。

- 暗青底、低对比网格、浅色工程线；网格不进入正文安全区的高频视觉层。
- 轮廓图、尺寸线和插槽标记是内容层，不烘焙进通用面板底图。
- 蓝图不替代普通信息面板，也不用于市场、委托等非技术页面。

### 3.4 Cloth Flag / 布旗

用途：主导航、港口/阵营识别和高语义入口。

- 所有布旗共享上方挂点、包边、下垂轮廓和文字安全区。
- 青色为普通入口，蓝色为地图/信息入口，红色只用于危险或出航等高承诺操作，中性浅布用于当前页或公共入口。
- 小尺寸二级页签不用布旗，改用黄铜钢板 `plate`，避免页面遍布悬挂物。

### 3.5 Glass / 玻璃浮层（3D 舞台上的操作坞）

用途：画在 3D 舞台上的浮层操作坞（船厂改装态右侧 dock），让场景从面板下透出。

- 深青底 `alpha ≈ 0.66` + 1 px 黄铜描边、圆角 10、内容边距 14/12；不使用不透明钢板底，否则会遮住 3D 舞台。
- 与 `SNInsetPanel` 无法复用：后者的 0.78 不透明度在舞台背景上仍然偏实，玻璃浮层需要更低 alpha 与更柔描边。
- 浮层只承载数据与操作，不承载长正文；文字仍用 `steel`/`brass` 令牌保证对比度。
- 同一页面最多一层玻璃浮层，叠两层会牺牲舞台可读性。
- Theme variation：`SNGlassPanel`（stylebox `GlassPanel`）。

## 5. 九宫格与不可拉伸区

源资产必须同时提供 `.png`、Godot 导入边距记录和一张标注图。九宫格纹理不内嵌文字、数值或业务图标。

| 材质资产 | 建议源尺寸 | 九宫格边距 L/T/R/B | 安全文字区 L/T/R/B |
| --- | --- | --- | --- |
| 黄铜钢板 `frame` | 192×192 @2× | 28 / 28 / 28 / 28 | 24 / 20 / 24 / 20 |
| 黄铜钢板 `plate` | 192×96 @2× | 24 / 20 / 24 / 20 | 20 / 12 / 20 / 12 |
| 黄铜钢板 `recess` | 128×128 @2× | 20 / 20 / 20 / 20 | 16 / 14 / 16 / 14 |
| 羊皮纸 | 192×192 @2× | 26 / 24 / 26 / 24 | 28 / 22 / 28 / 22 |
| 蓝图 | 160×160 @2× | 20 / 20 / 20 / 20 | 22 / 20 / 22 / 20 |
| 蓝图底板（改装线稿整列） | 841×299 @0.5×（母版 1860×846） | 56 / 54 / 56 / 54 | 66 / 62 / 66 / 62 |
| 布旗 | 224×184 @2× | 30 / 38 / 30 / 30 | 20 / 34 / 20 / 24 |

规则：

- 角件、铆钉、挂环、绳结、纸夹、蜡封、管弯头和布旗顶部挂点全部属于不可拉伸区。
- 蓝图底板只有边条与深蓝中心可拉伸，四角黄铜角件固定；参数、母版与运行纹理的派生关系见 [docs/design/ui_controls_v1/blueprint_panel/README.md](ui_controls_v1/blueprint_panel/README.md)。
- 中心拉伸区不得包含明显噪点、文字、完整划痕或可识别图案；否则拉伸后会暴露重复。
- 长面板优先使用“九宫格主体 + 独立角件/管件”组合，不制作多个长度版本。
- 布旗下摆允许纵向轻微伸缩，禁止横向把挂环和布边拉宽；超过标准宽度时改用并列旗或钢板页签。
- 文本、图标、进度条和点击区域必须完全位于安全文字区内；装饰可以越界但不得遮挡交互。

## 6. 字体系统

| 层级 | 字体 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | ---: | ---: | ---: | --- |
| Display | Noto Serif SC | 36 | 700 | 44 | 主菜单、章节结算 |
| H1 | Noto Serif SC | 28 | 700 | 36 | 页面标题 |
| H2 | Noto Serif SC | 22 | 700 | 30 | 卡片/面板标题 |
| Key Number | Noto Sans SC | 24 | 600 | 30 | 金币、资源、报价 |
| Body | Noto Sans SC | 15 | 400 | 22 | 正文、列表 |
| UI Label | Noto Sans SC | 14 | 600 | 20 | 按钮、页签、字段名 |
| Detail | Noto Sans SC | 12 | 400 | 18 | 次要说明 |
| Caption | Noto Sans SC | 11 | 600 | 16 | 编号、眉题、单位 |

- 960×540 下正文仍保持至少 13 px、按钮至少 13 px；优先减少内容而不是继续缩字。
- 数字使用 Noto Sans SC 的统一数字字形；表格列右对齐，整数不添加无意义小数。
- 标题负责风格，正文负责效率。禁止用手写/装饰字体承载长文本。
- 英文全大写只用于 11 px 眉题、编号和短标签；中文不人为增加字距。

## 8. 交互状态矩阵

| 状态 | 视觉变化 | 位移/尺度 | 声音 | 约束 |
| --- | --- | --- | --- | --- |
| Normal | 基础材质与边线 | 无 | 无 | 保持清晰轮廓 |
| Hover | 受光面 +8%，黄铜高光出现 | 上移最多 1 px，不缩放 | 轻微金属擦响，可关闭 | 不改变布局 |
| Pressed | 顶边变暗、下边减弱，内容内压 | 下移 2 px | 短机械扣声 | 释放后回到 Hover/Normal |
| Selected | 与内容区结构连接，保留语义标记 | 布旗下沉 3 px或铭牌锁入 | 卡槽声 | 不只换颜色 |
| Keyboard Focus | 外侧 2 px 黄铜焦点线，间隔 2 px | 无 | 无 | 始终可见，不与 Hover 混淆 |
| Disabled | 饱和度 −55%，亮度 −25% | 无 | 无 | 文字仍可读；旁边显示禁用原因 |
| Loading | 黄铜扫光或 3 段机械指示 | 不移动控件主体 | 可选低频运转声 | 超过 500 ms 才显示 |
| Success | 安全绿标记 + 对勾/盖章 | 可有一次短盖章 | 短确认声 | 300 ms 后仍保留静态结果 |
| Warning | 警告黄 + 明确风险文字 | 无持续缩放 | 一次提示音 | 禁止循环闪烁 |
| Danger | 锈红结构边 + 危险图标/文字 | 确认前不抖动 | 明确但短促 | 破坏性操作需二次确认 |

## 9. 动效规范

| 动效 | 时长 | 缓动 | 距离/幅度 |
| --- | ---: | --- | --- |
| Hover 进入/退出 | 120 / 100 ms | ease-out / ease-in | 0–1 px |
| Press / Release | 70 / 100 ms | ease-out | 2 px |
| 页签锁入 | 180 ms | cubic ease-out | 3–6 px |
| Tooltip 出现 | 120 ms | ease-out | 4 px + 透明度 |
| 面板进入 | 240 ms | cubic ease-out | 12–20 px |
| 合同盖章 | 260 ms | back-out，一次 | 6% → 100%，只回弹一次 |
| 资源数值/表针 | 200 ms | cubic ease-out | 从旧值到新值 |
| 同场景页面切换 | 280 ms | cubic in-out | 24–40 px |

- 常规交互不使用弹性循环、长距离漂浮、持续呼吸缩放或整页闪白。
- 港口连续舞台的市场/补给切换沿世界方向平移，不叠加黑场。
- 低动效模式：移除位置、缩放和表针补间；保留 ≤80 ms 的颜色/透明度状态切换。
- 同时运动的主要对象不超过三个；背景环境动效不计入，但必须低对比。

## 10. 组件与边框治理

生产组件只允许以下结构边框：

1. `brass_steel/frame`：承载页面或弹窗。
2. `brass_steel/plate`：按钮、二级页签、Badge。
3. `brass_steel/recess`：输入、仪表、资源槽。
4. `parchment/sheet`：账册和合同。
5. `blueprint/sheet`：技术信息。
6. `cloth_flag/nav`：主导航。

以下原因不足以创建新边框：页面不同、卡片更重要、需要“更丰富”、内容较少、开发者个人偏好。层级优先通过留白、字号、材质选择和位置表达；危险/成功通过状态覆盖层表达。

新增边框必须记录：语义用途、所属材质族、与现有结构无法复用的原因、九宫格和安全区、全部交互状态。缺任一项不得进入 Theme。

## 11. 第一批生产资产与验收

### 资产

- 黄铜钢板：`frame`、`plate`、`recess`，各含 Normal/Hover/Pressed/Disabled；Danger 使用状态覆盖层。
- 羊皮纸：通用 sheet、纸夹、蜡封、完成/失败印章。
- 蓝图：通用 sheet、网格平铺、尺寸线/插槽标记独立切片。
- 布旗：统一结构 + 中性/青/蓝/红色布面；图标与文字运行时叠加。
- 通用装饰：角件、铆接耳、绳结、挂钩、管弯头，全部可选挂载。
- 七枚导航图标：市场、委托、船厂、补给、情报、海图、出航。

### 验收

- 每个组件在 0.75×、1×、1.2× 显示比例下无角件拉伸、文字侵入和明显接缝。
- 中文 2/4/8 字、英文 8/16/24 字符和三位/六位数字均通过安全区测试。
- Normal/Hover/Pressed/Selected/Focus/Disabled/Danger 状态在深色与 3D 场景背景上均可辨认。
- 960×540 保留价格、持仓、风险、主要操作和禁用原因；装饰可降级。
- 市场纵向样片通过后，才把材质与状态写入生产 Theme；Concept V1 不作为像素对照图。

## 12. 已落地实现 V1（外部贴图皮肤管线）

> 实现细节、换肤步骤与已知缺口见 [UI_SKIN_PIPELINE.md](UI_SKIN_PIPELINE.md)。

- 控件与图标来自两份母版：`docs/design/ui_controls_v1/`（30 件无字控件）、`docs/design/ui_icons_v1/`（30 枚图标）；由 `pwsh ./tools/build_ui_skin.ps1` 生成 `assets/ui/skin/sn_v1/`（九宫格纹理、128px 图标、固定配件、`skin.json`）与 `assets/ui/theme/steam_navigator_theme.tres`（全部控件状态 = StyleBoxTexture）。
- 程序化 UI 统一走 `framework/ui/skin/sn_skin.gd`（`SNSkin`）：`panel()` / `button_style()` / `style()` / `icon()` / `color()` / `icon_rect()`；业务脚本禁止新建 `StyleBoxFlat`、禁止硬编码 skin 路径或十六进制业务色。
- 换肤：同名同尺寸覆盖 `assets/ui/skin/sn_v1/nine_slice|icons/` 即整体换肤（无需改代码）；改画布尺寸或九宫格边距时必须重跑生成器并 `-Check`。
- 已实现 Theme variation：按钮 6（Primary/Secondary/Danger/Ghost/Compact/Plate）、面板 10（含 Parchment/BlueprintSheet/Canvas/Glass/Chrome/StatusBar/BlueprintPanel）、Badge 4、标签 3、进度 3；输入/复选/滚动条/页签/Tooltip/Popup 同步纹理化。
- 尺寸预算（换肤必须复核）：TopChrome ≤130px、PortStatusBar 60px、侧牌 172×42、PageMargin 20/14/20/56；低于 38px 高的按钮用 `SNCompactButton`/`SNPlateButton`，不要套标准按钮九宫格。
- 九宫格纹理不内嵌文字/状态色；`SNGhostButton` 全状态 content margin 必须一致，避免 hover 改变布局。
- 保留绘制（数据/内容表现，不参与换肤）：海图海面/陆地/迷雾/航线、船厂线稿与槽位、sparkline、演出云；颜色必须来自 `SNSkin.color()` token。
- 验收命令：`pwsh ./tools/build_ui_skin.ps1 -Check`、`& ./tools/test.ps1 -Suite ui_skin`、`pwsh ./tools/capture_ui.ps1 -AllScreens`（1440×900 + 960×540 各 26 页）。
- V1 边界：Theme 绑定生成的皮肤目录，运行期多皮肤切换留后续；布旗（`flag_*`）尚未接入当前紧凑导航/侧牌布局；导航/船厂/行动类图标存在语义近似（缺口清单见管线文档 §6）。
