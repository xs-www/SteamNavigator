# SNBattleSim

独立的 2D 舰队战斗规则试验台。它不会接入 Godot 主流程，也不会修改战役存档；当前目标是快速验证舰船装配、视野、炮击、多武器与货船护航规则。

## 启动

在仓库根目录执行：

```powershell
node SNBattleSim/tools/serve.mjs
```

然后打开 `http://127.0.0.1:4174`。新版使用浏览器 ES 模块，不能直接双击 `index.html`；原始单文件验证台仍保留在 `greybox.html`。端口被占用时可先设置 `PORT` 环境变量覆盖默认值。

## 已实现范围

- 固定小型、中型、大型三种船体。
- 无限战场坐标；镜头按全部在场舰船的包围盒自动居中和缩放，不存在撞地图边缘。
- 每艘船独立配置用途、武器挂载、视野组件和装甲/引擎/操舵/货舱调校。
- 多武器拥有独立射程、最小射程、射界、装填、齐射弹数与炮弹飞行时间。
- 直射要求当前视野；曲射炮击可对 3.5 秒内的最后已知位置盲射，但承受额外命中惩罚。
- 侧弦炮只能在左右舷夹角内开火，一次装填发射整组齐射。
- 舰队共享视野；未发现目标隐藏，丢失目标保留 7 秒最后已知位置。
- 丢失当前视野后继续驶向最后已知位置，避免舰队交错后直接放弃追击。
- 货船携带可统计的货物价值，受威胁时优先脱离战场。
- 用户可创建武器组件，并导入/导出完整 JSON 配置。
- 固定随机种子，便于复现同一装配的结果。
- 船舶使用低加速度、有限转向率、渐进舵效和航向惯性，不能原地快速掉头。
- 航速与视野按接敌时间重新配平；整舰数值中的“视野航程”表示该舰以最高航速走完自身视野半径所需时间。
- 战斗视角可在蓝方、红方和双方全知之间切换；在舰队列表点击舰船后，中间战场显示该舰视野与每个挂载武器的独立射界，侧弦炮显示左右舷双扇区。
- 每艘可见战船在舰名上方显示逐挂载武器装填条：装填中显示剩余秒数与进度，完成后显示“就绪”；战争迷雾中的目标不会泄露装填状态。
- 原先写死的机动决策已抽成逐舰声明式战术状态机。装配器可调整目标优先级、最后位置追击、无接触动作、理想射距、接近/脱离阈值、低耐久脱离、交战航速、绕行方向和货船行为；战场舰名旁实时显示当前状态。
- 脱离采用进入/退出双阈值：近距或首次跌破耐久阈值时进入，达到配置的恢复距离后退出；低耐久不会逐帧重复触发。急转时舰船先减速转艏，速度方向被限制在船体前半球，避免货船倒着逃跑。
- 战斗事件显示在战场右上角 HUD；战场下方显示所选舰的实时耐久、航速、目标、状态原因、命中与武器装填。
- 装配器列出视野组件详细数据与整舰最终属性，调校滑块拖动时实时刷新数值。

## 测试

```powershell
node --test SNBattleSim/tests/simulation.test.mjs
```

测试覆盖固定船体、多武器槽位、货船派生值、自定义武器校验、视野发现和确定性。

## 边界

- 当前装配器是规则验证工具，不直接复用正式船厂存档结构。
- 装甲、引擎、操舵和货舱暂以数值调校表示；只有武器与视野组件拥有独立目录项。
- 尚未加入弹药库存、部位伤害、锅炉压力、冲撞艇和战后持久化；旧灰盒继续用于压力/冲撞专项验证。
