# SNBattleSim

独立的 2D 舰队战斗规则试验台。它不会接入 Godot 主流程，也不会修改战役存档；当前目标是快速验证舰船装配、视野、炮击、多武器与货船护航规则。

## 启动

在仓库根目录执行：

```powershell
node SNBattleSim/tools/serve.mjs
```

然后打开 `http://127.0.0.1:4174`。新版使用浏览器 ES 模块，不能直接双击 `index.html`；原始单文件验证台仍保留在 `greybox.html`。端口被占用时可先设置 `PORT` 环境变量覆盖默认值。

## 已实现范围

- 固定小型、中型、大型三种船体。
- 无限战场坐标；镜头按全部在场舰船的包围盒自动居中和缩放，不存在撞地图边缘。
- 每艘船独立配置用途、武器挂载、视野组件和装甲/引擎/操舵/货舱调校。
- 多武器拥有独立射程、最小射程、射界、装填、齐射弹数与炮弹飞行时间。
- 直射要求当前视野；曲射炮击可对 3.5 秒内的最后已知位置盲射，但承受额外命中惩罚。
- 侧弦炮只能在左右舷夹角内开火，一次装填发射整组齐射。
- 舰队共享视野；未发现目标隐藏，丢失目标保留 7 秒最后已知位置。
- 丢失当前视野后继续驶向最后已知位置，避免舰队交错后直接放弃追击。
- 货船携带可统计的货物价值，受威胁时优先脱离战场。
- 用户可创建武器组件，并导入/导出完整 JSON 配置。
- 固定随机种子，便于复现同一装配的结果。
- 船舶使用低加速度、有限转向率、渐进舵效和航向惯性，不能原地快速掉头。
- 航速与视野按接敌时间重新配平；整舰数值中的“视野航程”表示该舰以最高航速走完自身视野半径所需时间。
- 战斗视角可在蓝方、红方和双方全知之间切换；在舰队列表点击舰船后，中间战场显示该舰视野与每个挂载武器的独立射界，侧弦炮显示左右舷双扇区。
- 每艘可见战船在舰名上方显示逐挂载武器装填条：装填中显示剩余秒数与进度，完成后显示“就绪”；战争迷雾中的目标不会泄露装填状态。
- 战术状态机已抽离为独立全屏开发者工作台。左侧管理可编辑的默认状态机与自定义状态机（新增、复制、重命名、删除），中央大型画布拖拽节点，完整转移表始终显示每条转移的起点、条件、终点和优先级，无需逐条点线查看。
- 状态机提供侦察、巡航、接近、迂回、规避、机动、脱离、逃跑、交火、集火十种动作，以及视野、最后位置、射程、装填、侧弦、指挥官、耐久和货船威胁等模块化条件。参数区统一编辑目标优先级、射距阈值、交火航速等数值。
- 每艘船只挂载一个状态机；工作台与装配器均可切换挂载。每方可指定一艘指挥官，集火状态使用指挥官选定的可见目标。默认状态机可修改但不可删除，自定义状态机删除后相关舰船自动回退至默认状态机。
- 默认状态机只保留旧规则的巡航、接近、交火、脱离、规避五个状态；侦察、迂回、机动、逃跑和集火仍作为状态定义提供给自定义 FSM。
- 工作台左侧状态定义可直接拖入画布；从节点拉线到空白处会弹出“创建并连接新状态”，按 Delete 可删除当前状态。选中状态后，下方只显示其出向转移；每条转移支持多个条件的“且 / 或”聚合。
- 可从 `SNBattleSim/mods/` 下的散装模组目录、`.zip` 或 `.snavmod.zip` 读取船舶、武器、视野组件、状态定义与状态机，并把当前数据导出成游戏可识别的 `.snavmod.zip`。完整格式见 [状态与状态机模组数据约定](docs/FSM_MOD_CONTRACT.md)。
- “舰体装配”以固定三种舰体为基础，可从 Mod 船舶定义选择蓝图，再选择武器、视野组件和状态机组装成舰队实例；Mod 船舶不再在读取时强制塞入舰队。
- 工程继续自动保存在浏览器 `localStorage`，并可用“保存工程 / 读取工程”在 `SNBattleSim/user_data/workspace.json` 维护一份明确的持久化副本。
- 脱离采用进入/退出双阈值：近距或首次跌破耐久阈值时进入，达到配置的恢复距离后退出；低耐久不会逐帧重复触发。急转时舰船先减速转艏，速度方向被限制在船体前半球，避免货船倒着逃跑。
- 战斗事件显示在战场右上角 HUD；战场下方显示所选舰的实时耐久、航速、目标、状态原因、命中与武器装填。
- 所选舰的攻击目标在战场上使用红色连线与脉冲圆高亮；状态只决定机动，包括脱离、规避和逃跑在内的舰船只要武器射界合法就会继续开火。
- 装配器列出视野组件详细数据与整舰最终属性，调校滑块拖动时实时刷新数值。

## 测试

```powershell
node --test SNBattleSim/tests/simulation.test.mjs
```

测试覆盖固定船体、多武器槽位、货船派生值、十状态 FSM、AND/OR 条件聚合、模组数据往返、视野发现和确定性。

Agent 可使用零浏览器 CLI 快速检查：

```powershell
node SNBattleSim/tools/cli.mjs validate-mods
node SNBattleSim/tools/cli.mjs inspect
node SNBattleSim/tools/cli.mjs simulate --ticks 1200 --seed 5201
```

## 边界

- 当前装配器是规则验证工具，不直接复用正式船厂存档结构。
- 装甲、引擎、操舵和货舱暂以数值调校表示；只有武器与视野组件拥有独立目录项。
- 尚未加入弹药库存、部位伤害、锅炉压力、冲撞艇和战后持久化；旧灰盒继续用于压力/冲撞专项验证。
